A small release. If 2.1.1 is working for you, nothing changes about how presets
behave.

### Start with Windows is back

Settings has a **Start with Windows** switch again. When it's on, the app starts
in the tray when you log in, so hotkeys and alerts are ready without opening a
window.

Until now the app also removed its own startup entry every time it launched, so
it couldn't be turned on by hand through Task Manager's Startup list either.
That no longer happens. The switch reads the actual Windows startup entry, so if
you turn it off in Task Manager, the switch shows it as off too.
