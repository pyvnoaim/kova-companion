A small release. If 2.1.0 is working for you, nothing changes about how presets
behave.

### Fixed: how to load a theme mid-session

Applying a theme preset while KovaaK's is running rewrites the `!KovaPreset`
theme, and the app used to tell you to open the game's settings to see it. That
was wrong: KovaaK's only reloads a theme when you select it in the theme menu.
The app now gives the step that actually works: in KovaaK's, switch to any other
theme and back to `!KovaPreset`. No restart needed. Thanks to c1ayupmax for
reporting it (#1).

### Installer

The installer is now always called `kova-companion-setup.exe`, without a version
number, so there's one fixed download link. Because the name changed, this one
update downloads the full installer instead of only the changed parts. Later
updates are small again.
