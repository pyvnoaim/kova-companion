### Start with Windows switch fixed

In 2.1.3 and 2.1.4 the **Start with Windows** switch in Settings jumped back to
off every time you clicked it. Clicking it did register the app to start with
Windows, the switch just couldn't see that, so you may already have it on. It
now shows the real setting, including when you turn it off in Task Manager.
